VinaGridBox visualizes and edits AutoDock Vina search spaces with the six native parameters center_x/y/z and size_x/y/z. It includes selection-derived boxes, exact bounds, selection containment checks, box color and edge-visibility controls, mouse-based movement/resizing, and undo/redo for box edits.

Open the tool

Open Tools → Binding Analysis → Vina Grid Box, or enter:

vinabox showgui

Hide the panel without deleting the 3D box:

vinabox hidegui

Manual box entry and geometry

Enter center and size values in Angstroms (Å). The exact bounds are:

minimum = center - size / 2
maximum = center + size / 2

New box creates/updates the box; View box frames it; Copy Vina config copies the six values; and Clear removes the 3D box. The Exact box bounds section reports min/max coordinates on each axis.

Create a box from the current selection

Select the atoms in ChimeraX, choose a method, set Padding per side, and click Create box from selection. Both methods operate on the current atom selection.

Selection bounds + padding (recommended for pockets)

vinabox bounds padding 4

For each axis, find the minimum and maximum selected-atom coordinates, then expand both sides by padding:

minimum = min(q_i) - padding
maximum = max(q_i) + padding
center = (minimum + maximum) / 2
size = maximum - minimum

This is recommended for receptor pockets because it encloses the selected atoms with the requested padding on every face. Dimensions are not rounded to whole Angstroms or grid spacing.

Vina ligand-centroid method

vinabox centroid padding 4

This method uses the arithmetic mean of selected coordinates as the center, finds the furthest absolute excursion along each axis, adds padding, then rounds each size upward to a whole Angstrom. It is intended for ligand atom selections and comparison with Vina's ligand-derived box convention; it is not recommended for receptor-pocket selections.

The Vina source describes this centroid-based convention, but the maintainer has not found a clear published explanation in the reviewed source/documentation for why it was preferred over a minimum/maximum-centred padded box. The recommendation for the bounds method is specific to receptor-pocket selection, not a claim of universal superiority.

Padding defaults to 4 Å. Changing padding or switching methods recalculates an active selection-derived box from the saved selection coordinates. Editing center/size manually detaches the box from that saved selection so later padding changes do not overwrite manual values.

Check selection

Check selection does not modify the box. It reports how many selected atoms are inside/outside the current box and the maximum Cartesian overhang in Å if any are outside. If there is no box, it reports that a box must be created first.

Vina rounded map extent

Vina discretizes requested dimensions into a grid. Conceptually, for spacing 0.375 Å:

n = ceil(size / spacing)
grid_span = n * spacing

For example, a requested X size of 24.390 Å gives 66 grid intervals and a 24.750 Å reference span. The optional rounded-map-extent outline does not change the exported size_* values. The GUI's spacing field is a reference visualization setting, not a separate Vina configuration parameter.

Mouse interaction and display

Enable Mouse interaction to use:

  • Left-drag: move the whole box.
  • Right-drag: resize the face under the cursor while keeping the opposite face fixed.

While enabled, mouse interaction temporarily takes over the normal left/right mouse bindings. Uncheck the option to restore the previous bindings. Each completed gesture is undoable.

By default, molecular geometry occludes box faces/edges behind it. Enable Draw box on top (show edges through structure) to keep all box geometry visible. Box color… changes visualization only. These display features do not alter Vina calculations.

Native PDBQT opening

ChimeraX provides a built-in AutoDock PDBQT reader used by ViewDock. VinaGridBox does not register a separate PDBQT reader and does not add a separate PDBQT file-opening button. On initialization it makes the native format the preferred default for .pdbqt and clears a competing legacy default for that suffix. Normal ChimeraX file opening, including opening from Windows Explorer and drag-and-drop, can therefore use the native reader. Multi-pose docking files normally open in ViewDock; a single receptor or ligand opens as a molecular model.

If the saved/native format preference needs to be repaired manually, run:

vinabox nativepdbqt

To open a particular file explicitly through the built-in reader, use the ordinary ChimeraX command:

open "D:/docking/results.pdbqt" format pdbqt

CLI reference

vinabox set center 0,0,0 size 20,20,20
vinabox bounds padding 4
vinabox centroid padding 4
vinabox nativepdbqt
vinabox showgui
vinabox hidegui
vinabox report
vinabox clear

For set, each 3D value must be supplied as one comma-separated triple (for example, center 0,0,0, not center 0 0 0). Showing/hiding the GUI does not affect undo history. clear removes the 3D box but leaves the GUI open.

Undo and redo

Ctrl+Z or ChimeraX's undo command reverses numerical edits, vinabox set, selection-derived box creation, padding/method changes, each completed mouse drag, color changes (including those made through the Models panel), edge/map-extent toggles, and box creation/clearing. Redo is available through ChimeraX's normal redo command/shortcut. Rapid numerical edits are coalesced where possible. Showing or hiding the GUI is not undoable.

Coordinate consistency and limitations

Selection-derived calculations use ChimeraX atom scene coordinates. Ensure those coordinates match the receptor/ligand files supplied to Vina, especially if models have been transformed in the scene. VinaGridBox does not run docking, prepare PDBQT files, or select a scoring function.
